# 💼 Employee Salary Prediction Using Machine Learning

## Project Overview
This project predicts an employee's estimated salary based on experience, education level, and job role using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib

## Machine Learning Algorithm
Linear Regression

## Dataset
The dataset contains employee information with the following columns:
- Experience Years
- Education Level
- Job Role
- Salary

## Features
- Enter employee experience.
- Select education level.
- Choose job role.
- Predict estimated salary.
- View model performance.

## Model Performance
- Mean Absolute Error: 2083.33
- R² Score: 1.00

These results are based on a very small sample dataset and should not be treated as real-world performance.

## How to Run the Project

1. Install the required libraries:

   `pip install -r requirements.txt`

2. Run the application:

   `python -m streamlit run main.py`

## Conclusion
This project demonstrates how Linear Regression can be used to predict employee salaries based on selected employee details.
